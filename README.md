# Chicken Karahi Website - Image Assets Guide

This website requires the following images to be placed in the `assets/images/` directory:

## Required Images

### Hero Section
- `hero-karahi.webp` - Large appetizing karahi image for the hero section (Recommended: 1200x800px)

### Menu Items
- `chicken-karahi.webp` - Chicken Karahi dish image (Recommended: 600x400px)
- `special-karahi.webp` - Special Chicken Karahi dish image (Recommended: 600x400px)
- `mutton-karahi.webp` - Mutton Karahi dish image (Recommended: 600x400px)
- `tikka.webp` - Chicken Tikka dish image (Recommended: 600x400px)
- `naan.webp` - Garlic Naan bread image (Recommended: 600x400px)
- `raita.webp` - Raita side dish image (Recommended: 600x400px)

### Special Deal
- `family-karahi.webp` - Family Karahi Combo image (Recommended: 800x600px)

### About Section
- `about-us.webp` - Kitchen or restaurant interior image (Recommended: 800x600px)

### Gallery
- `gallery-01.webp` through `gallery-06.webp` - Various food photos (Recommended: 600x400px each)

## Image Guidelines

1. **Format**: Use WebP format for better compression and loading speed
2. **Size**: Compress images to balance quality and file size
3. **Alt Text**: All images have descriptive alt text for accessibility
4. **Placeholder**: Currently using placeholder.svg - replace with actual food photos

## Optional: Favicon
- Place a favicon.ico in the `favicon/` directory for browser tab branding

## Before Publishing
- Replace all placeholder images with high-quality, licensed food photos
- Update all placeholder contact information (phone, address, WhatsApp)
- Replace sample prices with actual menu prices
- Update Google Maps embed with real location
- Replace sample reviews with actual customer testimonials
